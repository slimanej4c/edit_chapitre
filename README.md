# edit_chapitre

## محرر المذكرات البيداغوجية في الرياضيات (Éditeur de Fiches Pédagogiques)

تطبيق متقدم ومكتمل لتعديل وتخصيص المذكرات البيداغوجية (خاصة في الرياضيات) للتعليم الثانوي الجزائري، دون أي تشويه أو إزاحة في المعادلات الرياضية أو الجداول أو التنسيقات الأصلية.

---

### ✨ المميزات الرئيسية (Fonctionnalités)
1. **كشف تلقائي وشامل لأرقام المذكرات (Détection Universelle) :**
   - كشف جميع أرقام المذكرات في الملف بغض النظر عن نوع التشفير (Unicode القياسي أو Presentation Forms أو الخطوط المخصصة).
   - استخراج عنوان الدرس / الموضوع (`الموضوع`, `المحتوى المعرفي`, `الوحدة`).
   - إمكانية تعديل أرقام المذكرات يدوياً أو تطبيق ترقيم تسلسلي تلقائي بضغطة زر.
   - تحديث تفاعلي فوري عند تغيير الملف أو لصق مسار جديد.

2. **تعديل معلومات الأستاذ والمؤسسة بدون أي تداخل :**
   - اسم الأستاذ (داخل الإطار البيضاوي أو كنص بجانب العنوان).
   - المؤسسة / الثانوية.
   - المستوى مع إمكانية ضبط الهامش (`Margin`) في الواجهة بدقة لتفادي أي تداخل.
   - السنة الدراسية في الصفحة الأولى وجداول الترويسة.

3. **حماية 100% للتنسيق والمعادلات الرياضية :**
   - استخدام تقنيات التحرير الدقيق (Redaction Vectorielle) للحفاظ على خطوط الجداول والرموز والرسومات المتجهية.

---

### 🖥️ طرق التشغيل (Comment Lancer)

#### 1. الواجهة الرسومية لسطح المكتب (Desktop GUI - Tkinter)
```bash
python editeur_desktop.py
```
- متوفر على Mac/Linux عبر الملف: `Lancer_Editeur.command`
- متوفر على Windows عبر الملف: `Lancer_Application_Windows.bat`

#### 2. تطبيق الويب التفاعلي (Streamlit Web App)
```bash
streamlit run app.py
```
- متوفر على Mac عبر الملف: `Lancer_Editeur_Web.command`

#### 3. توليد ملف تنفيذي مستقل لويندوز (Générer l'exécutable .EXE)
- على نظام Windows، قم بالنقر المزدوج على:
```
Generer_EXE_Windows.bat
```
سيقوم تلقائياً بتثبيت التبعيات وبناء ملف `Editeur_Fiches_Pedagogiques.exe` الذي يعمل بدون الحاجة لتثبيت بايثون.
